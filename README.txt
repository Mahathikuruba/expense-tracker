Expense Tracker App

Project Description:
A React + Firebase web application for managing daily expenses.

Features:
- User Signup/Login
- Add/Edit/Delete Expenses
- Category Filtering
- Budget Tracking
- Expense Analytics Chart
- PDF Report Generation
- Firebase Hosting Deployment

Tech Stack:
- React.js
- Firebase Authentication
- Firestore Database
- Firebase Hosting
